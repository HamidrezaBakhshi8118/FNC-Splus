# موتور داخلی FNC-Splus از نسخهٔ ۰٫۲٫۰

`SPlusthon` از وابستگی‌های نصب و importهای اجرا حذف شده است. توزیع Telethon نیز نصب یا import نمی‌شود. برای نصب همان دستور Git کافی است و وابستگی‌های رسانه به‌صورت پیش‌فرض نصب می‌شوند.

## منشأ کد و حدود بازنویسی

هستهٔ عمومی MTProto، مدیریت درخواست/پاسخ، entity، cursor دریافت و سازوکارهای عمومی پیام از سورس **MIT** پروژهٔ Telethon v1.36.0 در کامیت `04aea46fe43eaed98054a7333911f72e13262f46` گرفته شده و داخل `fnc_splus/_mtproto` نگهداری می‌شود. این بسته یک پیاده‌سازی مستقل از صفر یا clean-room معرفی نمی‌شود. مجوز و نام سازندگان اصلی حفظ شده‌اند و `UPSTREAM.json` هش فایل‌های اولیه را پیش از تغییر ثبت می‌کند. سورس GPL کتابخانهٔ SPlusthon به این توزیع منتقل نشده است.

بخش‌های اختصاصی FNC شامل جریان صریح OTP بدون get_me پیش از مجازشدن، آدرس‌های سروش، اتصال جداگانهٔ فایل، نوع‌های TL تولیدشده از طرح رسمی سروش، تبدیل سشن‌های hostname، AES-CTR/IGE و RSA مبتنی بر PyCryptodome، صف و سشن رمزنگاری‌شده است. public RSA keyها مستقیماً از باندل وب رسمی استخراج و fingerprint آن‌ها بررسی می‌شود؛ اطلاعات ورود حساب در سورس نیست.

برای تولید دوبارهٔ TL:

```bash
python scripts/build_internal_tl.py
python scripts/generate_methods.py
python scripts/build_docs.py
```

ژنراتور MIT و طرح سازگاری آن در `tools/mtproto_generator` همراه سورس هستند. سازنده‌های اضافی پایه فقط برای سازگاری داخلیِ کد موتورند؛ مرجع تأییدشدهٔ منبع سروش همچنان ۳۷۴ RPC و ۱۳۰۹ سازندهٔ رسمی است.

## سازگاری سشن و API

امضای `Client`، متدهای ارسال، آلبوم، رویدادها و مدل‌های نتیجه حفظ شده‌اند. سشن رمزنگاری‌شدهٔ نسخهٔ پیشین و کلید جانبی آن قابل استفاده است و برای مهاجرت سشن را پاک نکنید. StringSessionهای آدرس‌دار سروش و نوع قدیمی IPv4/IPv6 قابل خواندن هستند.

اشیای TL خارجی از یک نصب جداگانهٔ SPlusthon/Telethon را با موتور داخلی ترکیب نکنید. در کد برنامه، `types`، `functions`، `events` و `errors` را از `fnc_splus` وارد کنید. `client.native` اکنون موتور داخلی است؛ دسترسی به جزئیات خصوصی موتور خارجی قرارداد پایداری این API نیست.

## بررسی واقعی انجام‌شده

- نصب wheel در محیط بدون SPlusthon، Telethon، pyaes و rsa و import موفق موتور داخلی.
- مذاکرهٔ واقعی RSA/DH و ساخت کلید MTProto تازه بدون شماره، OTP یا حساب کاربری.
- بازکردن سشن رمزنگاری‌شدهٔ قبلی، مجازبودن و خواندن پیام‌های ذخیره‌شده بدون OTP.
- متن، ریپلای، عکس، H.264 با تامنیل، آلبوم ترکیبی و فوروارد فقط در Saved Messages؛ بازخوانی سرور و دانلود و decode عکس/فیلم.
- ارسال یک علامت آزمایشی از وب رسمی به Saved Messages و دریافت آن توسط inbox موتور داخلی.

ورود تازه با دریافت OTP در این دور دوباره روی حساب واقعی اجرا نشده است. مسیر درخواست کد/ورود با تست محلی بررسی شده؛ مذاکرهٔ کلید تازه و استفاده از سشن موجود، بررسی واقعی جداگانه داشته‌اند. پایداری چندروزه و اجرای واقعی همهٔ RPCهای حساب ادعا نمی‌شود.
